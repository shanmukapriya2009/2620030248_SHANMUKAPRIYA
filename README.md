Project Abstract: Flight Status Tracker

Team Members: Navya Chowdary B — 2620030093

Shanmuka Priya — 2620030248

Summary The Flight Status Tracker is a responsive web application designed to help travellers quickly look up flight details and monitor journey updates through a clean, accessible interface. By combining intuitive search forms with clear visual status indicators, the application eliminates confusion around schedule changes and presents essential flight information in an easy-to-scan format.

Through the platform, users can search by flight number, route, or travel date to view real-time or scheduled flight status (such as on-time, delayed, boarding, or landed), planned versus actual departure and arrival times, airport details, terminal numbers, and gate assignments. Colour-coded badges and structured layouts highlight schedule adjustments immediately, helping travellers and those picking them up plan airport arrivals and connections with greater confidence across both desktop and mobile devices.
